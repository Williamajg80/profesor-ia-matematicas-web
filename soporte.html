Ayuda

Soporte

Cómo obtener ayuda con Profesor IA Matemáticas, reportar errores y conocer las limitaciones actuales.

Canales de ayuda

  • GitHub Issues (canal principal). Los errores, dudas y sugerencias se reciben en la sección de incidencias del repositorio público del sitio: github.com/Williamajg80/profesor-ia-matematicas-web/issues. Para crear una incidencia se necesita una cuenta gratuita de GitHub.
  • Esta página. Reúne las preguntas frecuentes y el estado actualizado de las funciones.

Las respuestas se dan en la medida de lo posible y sin un plazo garantizado, ya que se trata de un proyecto educativo individual.

Las incidencias de GitHub son públicas

Cualquier persona puede leer lo que escriba. No incluya datos personales, información de estudiantes, calificaciones, contraseñas ni documentos confidenciales.

Cómo reportar un error

  1. Abra GitHub Issues y pulse «New issue».
  2. Escriba un título breve que describa el problema.
  3. Indique qué estaba haciendo, qué esperaba que ocurriera y qué ocurrió.
  4. Si aplica, añada un fragmento mínimo del texto o del código LaTeX que reproduce el problema, sin datos personales.
  5. Indique la fecha aproximada y, si lo sabe, el navegador o la aplicación que usaba.

Preguntas frecuentes

¿Qué es Profesor IA Matemáticas?

Es un complemento de inteligencia artificial que apoya la planificación de clases, las secuencias didácticas, las guías, los talleres, las evaluaciones y la elaboración de documentos académicos en LaTeX.

¿El complemento genera archivos PDF?

Todavía no mediante el servidor MCP. La compilación está deshabilitada por seguridad. El complemento entrega el código LaTeX, que puede compilarse en Overleaf o en una instalación local de LaTeX.

¿Puedo usar el código LaTeX en Overleaf?

Sí. Copie el código en un proyecto de Overleaf y compílelo allí. Si aparece un error de compilación, puede reportarlo con el fragmento que lo produce.

¿Los contenidos generados son siempre correctos?

No. Los contenidos generados con IA pueden contener errores matemáticos, de notación o pedagógicos. Revíselos siempre antes de usarlos con estudiantes.

¿Es un producto oficial de OpenAI?

No. Es un proyecto independiente desarrollado por William Jiménez y no ha sido aprobado ni respaldado por OpenAI.

¿Tiene costo?

Este sitio y el canal de soporte son gratuitos. El uso del complemento puede requerir una cuenta en la plataforma donde se utiliza, sujeta a las condiciones de esa plataforma.

¿Qué hago con una duda sobre privacidad?

Consulte la política de privacidad. Si su consulta incluye información personal, no la publique en una incidencia; abra una incidencia solicitando un medio de contacto privado.

Limitaciones actuales

  • La compilación de PDF mediante el servidor MCP está deshabilitada.
  • Los resultados dependen del modelo de IA y pueden contener errores; requieren revisión humana.
  • El servidor MCP se aloja en un servicio en la nube y puede tener interrupciones o demoras al iniciar.
  • El soporte es individual y no tiene tiempos de respuesta garantizados.
  • El complemento está pensado para usarse en español.

Estado de la compilación PDF

Deshabilitada

La herramienta compilar_latex del servidor MCP no ejecuta documentos. Cuando se invoca, responde que la compilación está deshabilitada hasta configurar un servicio aislado. Esta decisión evita ejecutar código LaTeX arbitrario en un servidor expuesto a Internet. La función solo se habilitará cuando exista un entorno de compilación aislado, efímero y con límites de recursos.
