Política de privacidad

Última actualización: 14 de octubre de 2026 · Versión 1.0

Esta política explica qué información puede tratarse cuando se usa el complemento Profesor IA Matemáticas y este sitio web. Describe solo prácticas que el desarrollador ha podido comprobar en el código y la configuración actuales del proyecto.

1. Quién desarrolla el complemento

Profesor IA Matemáticas es un proyecto educativo individual desarrollado por William Jiménez. No es un producto de OpenAI ni ha sido aprobado o respaldado por OpenAI.

2. Información que pueden introducir los usuarios

Para preparar materiales, los usuarios pueden escribir en la conversación información como:

  • temas, niveles, objetivos y condiciones de un curso;
  • textos, ejercicios, enunciados y código LaTeX;
  • comentarios y decisiones sobre las propuestas del complemento.

El complemento no necesita datos personales de estudiantes ni de terceros para funcionar. Le pedimos no introducir nombres de estudiantes, calificaciones, documentos de identidad, datos de salud ni otra información sensible.

Las conversaciones ocurren en la plataforma de OpenAI (por ejemplo, ChatGPT) y son tratadas por OpenAI según sus propias políticas. El desarrollador del complemento no tiene acceso al historial de conversaciones de los usuarios en esa plataforma.

3. Información enviada al servidor MCP

El complemento puede usar un servidor MCP del proyecto, alojado en Render en profesor-ia-matematicas-mcp.onrender.com. El asistente solo envía información al servidor cuando invoca una de sus herramientas:

  • estado_compilacion: no recibe contenido del usuario.
  • compilar_latex: recibe un parámetro de texto con el código LaTeX que se quiere compilar.

En la versión actual, el código del servidor no compila, no guarda en archivos o bases de datos y no devuelve el código LaTeX recibido. Solo responde que la compilación está deshabilitada. El servidor no tiene base de datos.

Como en cualquier conexión web, el servidor y la infraestructura de alojamiento también reciben datos técnicos de la petición, como la dirección IP de origen, la fecha y hora, la ruta solicitada y las cabeceras HTTP. El protocolo MCP asigna además un identificador de sesión técnico que el servidor mantiene en memoria mientras la sesión está activa.

4. Para qué se usa la información

  • Responder a las solicitudes de las herramientas del servidor MCP.
  • Mantener el funcionamiento técnico, diagnosticar errores y proteger el servicio frente a usos abusivos.

La información no se vende, no se usa con fines publicitarios y el desarrollador no la usa para entrenar modelos de inteligencia artificial.

5. Registros técnicos

El servidor usa un servidor web estándar (Uvicorn) que, en su configuración predeterminada, escribe registros de acceso con la dirección IP de origen, el método y la ruta de la petición y el código de respuesta. Esos registros no incluyen el contenido LaTeX enviado a las herramientas.

Render recoge y conserva los registros del servicio durante el tiempo que establezca su plan y sus políticas. Además, Render y sus proveedores de red pueden mantener sus propios registros técnicos y de seguridad. El desarrollador puede consultar esos registros desde el panel de Render solo para fines de diagnóstico y seguridad.

Si usa Overleaf u otro servicio para compilar el código LaTeX, ese uso queda fuera del complemento y se rige por las políticas de ese servicio.

7. Este sitio web

Este sitio es estático. No usa cookies, formularios, herramientas de analítica, publicidad ni rastreadores, y no carga tipografías ni scripts de terceros. GitHub, como proveedor de alojamiento, puede registrar datos técnicos de las visitas, como la dirección IP, por motivos de seguridad y funcionamiento.

Las incidencias que se publican en GitHub Issues son públicas y quedan asociadas a la cuenta de GitHub de quien las escribe.

8. Medidas de seguridad

  • Las conexiones con el servidor MCP y con este sitio se hacen mediante HTTPS.
  • La compilación de LaTeX está deshabilitada para no ejecutar código arbitrario en un servidor expuesto a Internet.
  • El servidor no guarda en archivos o bases de datos el contenido que recibe.
  • El repositorio del servidor es privado y no contiene credenciales.
  • El servidor tiene un alcance mínimo: dos herramientas, sin acceso a cuentas ni archivos de los usuarios.

Ningún sistema es completamente seguro, por lo que no se puede garantizar una seguridad absoluta. Actualmente, el servidor MCP no exige autenticación porque sus herramientas no acceden a información de los usuarios ni ejecutan código. Se añadirán controles adicionales antes de habilitar funciones que lo requieran.

9. Recomendaciones para los usuarios

  • No introduzca datos personales de estudiantes ni información confidencial.
  • No incluya contraseñas, claves ni credenciales en el código LaTeX o en los mensajes.
  • No publique información personal en GitHub Issues.

10. Consultas sobre privacidad

Para preguntas o inquietudes sobre privacidad, abra una incidencia en GitHub Issues con el título «Privacidad». No escriba datos personales en la incidencia; si su consulta los requiere, solicite en ella un medio de contacto privado. Para solicitudes sobre los datos de sus conversaciones, diríjase a OpenAI mediante sus canales oficiales.

11. Limitaciones

Esta política se refiere al complemento Profesor IA Matemáticas, a su servidor MCP y a este sitio. No sustituye las políticas de OpenAI, Render, GitHub u otros servicios que intervengan, sobre cuyo tratamiento de datos el desarrollador no tiene control. Este proyecto no declara certificaciones de seguridad ni de cumplimiento normativo.

12. Cambios en esta política

Esta política se actualizará cuando cambie el funcionamiento del complemento, en especial si se habilita la compilación de PDF. La fecha de la última actualización aparece al inicio de esta página, y el historial de cambios puede consultarse en el repositorio público del sitio.
